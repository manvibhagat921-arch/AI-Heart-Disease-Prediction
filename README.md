# AI-Heart-Disease-Prediction
AI-based Heart Disease Prediction System using Machine Learning. Built with Python and Flask, this project analyzes patient health data to predict heart disease risk. Includes data preprocessing, model training, and a user-friendly web interface.
Machine Learning-based Heart Disease Prediction system using Python, Pandas, and Scikit-learn. Implements data preprocessing, feature selection, and classification models with a Flask web app for real-time prediction.
